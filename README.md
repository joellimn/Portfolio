# MP3 Design Portfolio

Joel Lim’s UX portfolio — an iPod Classic–inspired experience built from the [Portfolio-MP3 Figma file](https://www.figma.com/design/Q6g2C50Tgm8nj4B9kKVdSl/Portfolio-MP3).

## Stack

- Next.js (App Router, TypeScript)
- Tailwind CSS
- Framer Motion
- Lucide React

## Experience

1. **Hero** — centered iPod with name, tagline, and “Scroll to view works”
2. **Zoom** — scroll locks the device center-stage and scales into the screen; click wheel fades away
3. **Cover Flow** — project covers (SOAR, UMG, and more)
4. **Case study** — full-width reading surface with a persistent **Now Playing** bar + blue scroll progress

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
